# delta-observatory/.github

This repository holds the organization profile and the default community files of the `delta-observatory` GitHub organization.

| File | Use |
|---|---|
| `profile/README.md` | The organization page on GitHub. |
| `SECURITY.md` | The security policy of each public repository that has no policy of its own. |

The project starts at the [entry repository](https://github.com/delta-observatory/delta-observatory).
