# Security policy

This policy applies to each public repository of the `delta-observatory` organization that has no policy of its own.

## Report a vulnerability

Use private vulnerability reporting: open the **Security** tab of the affected repository and select **Report a vulnerability**.
Do not open a public issue for a vulnerability.
Give the affected repository, the commit, the steps to reproduce, and the expected impact.

## Scope

Delta Observatory is a personal research project. No public instance of the application runs.
Reports about the API's authentication, permission checks, campaign rules, evidence exports, and the MCP adapter are in scope.
The project gives no response time and no bounty.
